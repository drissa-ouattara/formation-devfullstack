# HTML — Cours

> Objectif : comprendre le HTML, sa structure, sa sémantique et son rôle dans le développement web.
> Aperçu de ce qu'il faut apprendre à ce stade.

## 1. Fondamentaux du HTML

- Rôle du HTML
- Structure d'un document HTML
- `<!DOCTYPE html>`
- `<html>`, `<head>`, `<body>`

- Titres et paragraphes

- Titres : `<h1>` à `<h6>`
- Paragraphes : `<p>`
- Listes :

  - `<ol>`
  - `<li>`
- Citations

  - `<strong>`
  - `<em>`

- Ancres
- Navigation entre pages
- Attributs utiles (`target`, `rel`)

- `alt`

- `<audio>`

- `<figure>` / `<figcaption>`
