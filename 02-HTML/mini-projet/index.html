Mini-Projet HTML : Découvrir Node.js

Node.js est une plateforme logicielle libre en JavaScript, orientée vers les applications réseau évènementielles hautement concurrentes qui doivent pouvoir monter en charge. Node.js a été créé par Ryan Dahl en 2009. Son développement et sa maintenance sont effectués par l'entreprise Joyent. Dahl a eu l'idée de créer Node.js après avoir observé la barre de progression d'un chargement de fichier sous Flickr : le navigateur ne savait pas quel pourcentage du fichier était chargé et devait adresser une requête au serveur web.Dahl voulait développer une méthode plus simple.

Documentation Node.js

Introduction

Node.js est un environnement d’exécution JavaScript côté serveur, basé sur le moteur V8 de Chrome. Il permet d’exécuter du JavaScript en dehors du navigateur, ce qui le rend particulièrement adapté pour le développement de serveurs web, d’API et d’applications temps réel.

Installation

Node.js est un environnement d'exécution pour JavaScript côté serveur. L'installation varie selon le système d'exploitation. Voici l' étapes d'installation pour systèmes windows : Cliquez ici.

Concepts fondamentaux

Voici les concepts fondamentaux à comprendre pour bien débuter :

  • L’asynchronicité et la boucle d’événements,
  • L’utilisation de modules et npm,
  • La création de serveurs HTTP,
  • La gestion d’événements avec EventEmitter.

Les modules

En Node.js, les modules permettent d’organiser le code en différents blocs réutilisables et d’accéder à des fonctionnalités spécifiques. Il existe plusieurs types de modules : intégrés, externes et locaux.

  1. Modules intégrés
    • fs : opérations sur les fichiers
    • http : création de serveurs HTTP
    • path : manipulation de chemins de fichiers
    • os : informations sur le système d’exploitation
  2. Modules externes
    • express : framework pour créer des serveurs web,
    • mongoose : manipuler MongoDB,
    • axios : effectuer des requêtes HTTP,
    • etc...
  3. Modules locaux

    Vous pouvez créer vos propres modules pour structurer votre projet.

Exemple de code

Voici un exemple d'implémentation du programme Hello World sous forme de serveur web : 

                    
                        const { createServer } = require('http');
                        
                        //Creation du serveur
                        const server = createServer((request, response) => {
                            response.writeHead(200, {'Content-Type': 'text/plain'});
                            response.end('Hello World\n');
                        });
                        
                        server.listen(3000, () => console.log('Adresse du serveur : http://localhost:3000'));

Vous pouvez créer vos propres modules pour structurer votre projet : 

                    
                        // fichier mathUtils.js
                        function addition(a, b) {
                        return a + b;
                        }
                        module.exports = { addition };
                    
                
                    
                        // fichier main.js
                        const mathUtils = require('./mathUtils');
                        console.log(mathUtils.addition(2, 3)); // 5

Étapes d'installation

  1. Télécharger la version LTS depuis le site officiel.
  2. Installer Node.js en suivant l'assistant.
  3. Vérifier l'installation avec les commandes node --version et npm --version.
  4. Créer un dossier et initialiser le projet avec npm init.
