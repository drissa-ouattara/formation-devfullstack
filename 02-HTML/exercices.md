# Exercices HTML

## Exercice 1 — Première page HTML

**Statut : 🟢 Validé**

Création d'une première page de présentation permettant de pratiquer les fondamentaux du HTML.

Fichier :
`index.html`

Notions pratiquées :

- Structure minimale d'une page HTML
- Titres
- Paragraphes
- Listes
- Liens
- Images
- Formulaires
- `label` / `input`
- `id` / `name`
- Accessibilité avec `alt`

## Exercice 2 — Page HTML sémantique

**Statut : 🟢 Validé**

Création d'une page de blog technique en utilisant une structure HTML sémantique.

Fichier :
`index2.html`

Notions pratiquées :

- `header`
- `nav`
- `main`
- `section`
- `article`
- `footer`
- Hiérarchie des titres
- Relations parent / enfant / frères-sœurs
- Choix des éléments selon leur sens sémantique
