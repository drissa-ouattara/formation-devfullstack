Mes compétences

À ce stade de mon parcours, les notions vues jusque‑là concernent :

INTERNET

Internet est un réseau qui interconnecte plusieurs équipements informatiques à travers le globe. Il s'agissait jadis d'un projet qui était la propriété exclusive de l'armée américaine, sous le nom d'« ARPANET ». Aujourd'hui, il est utilisé aux quatre coins du globe par tous. Pour le parcours Full Stack, certains éléments d'Internet seront indispensables à connaître. Je vous en présente quelques-uns.

UNE URL

Une URL (Uniform Resource Locator) est une adresse permettant de localiser une ressource sur le Web. Elle contient plusieurs informations, à savoir :

  • Le protocole;
  • Le nom de domaine;
  • Le chemin (path);
  • Les paramètres (Query string)

LE DNS

Les ordinateurs communiquent entre eux grâce aux adresses IP et non aux noms de domaine. Le DNS (Domain Name System) est un service chargé de traduire un nom de domaine (par exemple www.google.com) en adresse IP (IPv4/IPv6) afin que l'ordinateur puisse contacter le bon serveur.

TCP

TCP (Transmission Control Protocol) est un protocole de transport (couche 4 du modèle OSI). Son rôle est de garantir une communication fiable entre deux machines.

TLS

TLS (Transport Layer Security) assure la sécurité des échanges entre le client et le serveur. Il garantit :

  • La confidentialité des données en les chiffrant;
  • L'intégrité des données;
  • L'authentification du serveur grâce au certificat numérique.

HTTP

HTTP (HyperText Transfer Protocol) est le protocole utilisé pour communiquer entre un client et un serveur Web. Ainsi, il permet au client de demander une ressource et au serveur de lui répondre.

LES MÉTHODES HTTP

Il s'agit de mots-clés utilisés pour manipuler des données. Les plus courants sont :

  • POST : envoyer des données vers le serveur ;
  • GET : Lire une ressource;
  • PUT : Remplacer complètement une ressource;
  • PATCH : modifier partiellement une ressource ;
  • DELETE : supprimer une ressource.

CODES HTTP

Les codes HTTP sont très utiles, notamment pour identifier le type de réponse venant du serveur. En voici quelques exemples :

Principaux codes HTTP
Codes Significations
200 : OK Requête réussie
201 : Created Ressource créée
204 : No Content Succès sans contenu
400 : Bad Request Requête invalide
401 : Unauthorized Authentification requise
403 : Forbidden Permissions refusées
404 : Not Found Ressource introuvable
500 : Internal Server Error Erreur interne du serveur

API REST

Une API (Application Programming Interface) est une interface permettant à deux programmes de communiquer. Une API REST est une API qui utilise les principes de REST et les méthodes du protocole HTTP (GET, POST, PUT, PATCH, DELETE...) pour manipuler des ressources.

JSON

JSON (JavaScript Object Notation) est un format texte permettant d'échanger des données entre différents programmes. Il est indépendant des langages de programmation et peut être utilisé par JavaScript, Python, PHP, Java, C#, Go et bien d'autres. Les API REST utilisent très souvent JSON pour envoyer et recevoir des données.

JWT

JWT (JSON Web Token) est un standard permettant de représenter les informations d'authentification sous la forme d'un jeton (token) : `xxxxx.yyyyy.zzzzz` (Header.Payload.Signature). Après une authentification réussie, le serveur génère un token signé qu'il renvoie au client. Le client conserve ce token et le renvoie au serveur à chaque requête, généralement dans l'en-tête HTTP `Authorization`. Le serveur vérifie alors la validité du token avant d'autoriser l'accès aux ressources demandées.

HTML

HTML (HyperText Markup Language) est un langage de balisage conçu pour structurer un site web. Il détermine l'ossature d'une page web. Depuis sa création, il n'a cessé d'évoluer sous diverses versions ; aujourd'hui, nous en sommes à sa version 5.

HTML sémantique

Les balises sémantiques permettent de donner du sens et de structurer le contenu d'une page. 

                                
                                    Exemples :
                                    <header> : contenu introductif d'une page ou d'une section.
                                    <nav> : zone contenant des liens de navigation.
                                    <main> : contenu principal de la page.
                                    <section> : section thématique du document.
                                    <footer> : pied de page ou d'une section.

Structure minimale d'une page HTML

                                
                                    Une page HTML possède une structure minimale :
                                    <!DOCTYPE html>
                                    <html lang="fr">
                                    <head>
                                    <meta charset="UTF-8">
                                    <title>...</title>
                                    </head>
                                    <body>
                                    ...
                                    </body>
                                    </html>

CSS

CSS (Cascading Style Sheets) est un langage de style utilisé pour décrire la présentation des documents HTML et XML. Il permet aux développeurs de contrôler l'esthétique d'une page web, à savoir : les espacements, la police d'écriture, les couleurs, le responsive design et bien d'autres éléments.
Voyons quelques concepts clés.
