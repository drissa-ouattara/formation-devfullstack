# Règle de progression

Une notion n'est considérée comme **validée** que lorsque :

1. le concept est compris ;
2. il a été expliqué avec ses propres mots ;
3. il a été pratiqué lorsque cela est pertinent ;
4. les éventuelles erreurs ont été corrigées.

On ne passe pas au bloc suivant simplement parce que le cours est terminé.
